# Aproved

Jogo idle em PT-BR sobre construir uma rede elétrica, era a era. Vite + React + TypeScript, Zustand, Phaser, Vitest.

```sh
npm install
npm run dev        # abre o jogo
npm test           # testes da simulação
npm run typecheck  # tsc --noEmit
npm run build      # produção em dist/
```

Leia `CLAUDE.md` (estrutura e regras), `docs/ESTADO.md` (o que existe e o que falta) e `docs/sessoes/` (especificação de cada sessão).
