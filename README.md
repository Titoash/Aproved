# Kardashev (codinome)

Jogo idle web de gerenciamento de energia em duas camadas, Rede e Núcleo, do cata-vento à esfera de Dyson.
Vite + React + TypeScript, Zustand, Phaser 3, Vitest.

```sh
npm install
npm run dev        # abre o jogo
npm test           # Vitest
npm run typecheck  # tsc --noEmit
npm run build      # produção em dist/
```

Leia `CLAUDE.md` (regras do projeto), `docs/GDD-parte1.md` (contrato de design), `docs/ESTADO.md` (o que existe e o que falta) e `docs/sessoes/` (uma especificação por sessão).
